# Memory Contract

Schema v7 gives each pet a local-only memory v1. Raw records are identified as `memory:<source_event_id>`, sequence-ordered, idempotently projected, and capped at 64 by lowest-importance then oldest-sequence eviction. Working (latest 8), episodic (importance ≥3), and emotional (non-neutral) memories are pure views; routine and semantic summaries are persistent projections.

Only pet events are recorded: hatch, care/routine actions, `pet_grew`, CRITICAL, stabilization and death. `pet_grew` is a positive LIFECYCLE memory of importance 4 and retains its deterministic transition payload; it does not mutate routine or semantic care summaries. Routine projections are caused only by actual `pet_fed`, `pet_drank`, `pet_washed`, `pet_touched`, `pet_played`, `pet_sleep_started`, and `pet_woke` events. A `pet_stabilized` survival record can retain the causal action for audit, but never increments that action's routine counters. `memory_version` is the strict integer `1`; sequences and record fields are strongly validated as declared scalar/category types. There is no migration backfill, language generation, or cross-pet inheritance. Death freezes memory; a memorial preserves the complete snapshot.
