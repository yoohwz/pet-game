# Product Contract

The future pet is offline-first: the device is authoritative for its private lifecycle, with real-world elapsed time reconciled on launch and no continuous background process. Core lifecycle, memory, language and memorial data must work without a backend. Pet identity is immutable; death is permanent. An egg is not a pet and has no `born_at` until a present-player hatching transaction creates a pet. Private memories stay local by default. Online features are optional future adapters, never core authority.
