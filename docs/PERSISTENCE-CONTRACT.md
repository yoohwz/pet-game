# Persistence Contract

Local `user://profile.json` is schema v8 and atomically includes pet activity/survival/growth state, relationship, Memory v2 language projections, and durable memorial snapshots. Biological simulation remains v6. v7 active/memorial pets migrate to Memory v2 while preserving retained records and adding an empty language summary; eggs only receive schema-v8 normalization. Accepted language messages are candidate-saved together with their `pet_heard_message` and projected memory; a failed candidate leaves no authoritative message/event/summary. Because Godot JSON parses number literals as floats, the migration boundary canonicalizes only mathematically exact whole floats for strict fields, including language payload versions/sentiment and language semantic counters; fractional values remain invalid. Existing validated-temp and known-good backup guarantees remain.
