# Persistence Contract

Local `user://profile.json` is schema v2 and atomically contains profile, simulation timestamp, and optional `active_pet` together. A v1 normal profile migrates without inventing a pet: it gains `active_pet: null`, simulation/balance version 2/1, and drops the proof-only elapsed field. Saves validate state, flushed temp, and critical directory/copy/rename results. Only a validated canonical file may rotate into backup; corrupt primary never overwrites valid backup, and replacement failure retains a known-good copy. Autosave is modest (30 seconds) and pause/debug reconciliation saves explicitly.
