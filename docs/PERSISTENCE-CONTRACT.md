# Persistence Contract

Local `user://profile.json` is schema v6 and atomically includes pet activity/survival state, relationship/memory and durable memorial snapshots. v5 active pets and nested memorial snapshots migrate to relationship v1 and fresh empty memory v1 without event backfill; biological simulation remains v5. `memorial_count` may be greater than `memorials.size()` to preserve pre-snapshot historical memorials, and a new memorial increments that count rather than recalculating it. New Egg eligibility requires a snapshot-backed memorial (`memorial_count > 0` and non-empty `memorials`), and Presentation uses the same predicate so historical count-only state exposes no impossible action. Explicit care candidates atomically include biological, relationship, memory and event changes. Existing validated-temp and known-good backup guarantees remain.
