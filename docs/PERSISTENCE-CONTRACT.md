# Persistence Contract

Local `user://profile.json` is schema v3 and atomically contains simulation, optional egg, and optional pet together. Root validation rejects missing/mixed subjects and malformed reservation state. v2 NONE migrates with no egg and is issued one egg by Application at current wall time; v2 PET is preserved and never receives a concurrent egg. HATCHING stores complete reserved identity (ID + seed + start) before any pet exists. Completion saves a PET candidate atomically; save failure leaves durable HATCHING intact. Startup offline reconciliation persists READY without creating a pet.
