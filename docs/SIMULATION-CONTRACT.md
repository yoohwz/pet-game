# Simulation Contract

`SimulationKernel.simulate(profile, from_timestamp, to_timestamp, balance)` takes explicit UTC seconds and balance configuration and produces deterministic state/events. For an active living pet it directly decays hunger (48h), hydration (24h), energy (16h), and hygiene (72h), clamped to 0–100. Mood and health do not decay; zero needs have no health/death consequence in Phase 1. Offline/resume reconciliation and Debug Time Machine use this same path. Foreground progression derives effective time from a monotonic session anchor, not frame delta or repeated wall time. Negative wall time yields zero elapsed and increments `clock_anomaly_count`. Event IDs include simulation/balance versions, pet ID (or profile ID), and interval. No per-second loops are used.
