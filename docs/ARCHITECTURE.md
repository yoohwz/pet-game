# Architecture

`Presentation → Application → Domain`; Infrastructure implements persistence for Application. Domain owns validation, formula-based awake/sleep/survival simulation, absolute-age GrowthModel transitions, canonical `DomainEvent` construction and deterministic biological event ordering, relationship rules, memory projection and memory queries with explicit configs. Application owns config loading, care, relationship/memory candidate transactions, rescue, memorial and new-egg commands, clock synchronization and persistence. Presentation owns stable state controls and read-only summaries; it never applies biological rules. Domain has no filesystem, clock, UI or network dependency.
