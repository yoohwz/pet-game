# Architecture

`Presentation → Application → Domain`; Infrastructure implements persistence for Application. Domain owns validation, formula-based awake/sleep/survival simulation, absolute-age GrowthModel transitions, canonical `DomainEvent` construction and deterministic biological event ordering, relationship rules, memory projection/query, and pure language normalization/classification from supplied rules and memory. Application owns config loading, care/language candidate transactions, rescue, memorial and new-egg commands, clock synchronization and persistence. Presentation owns stable state controls plus non-persistent language diagnostics; it never applies biological/language rules or generates pet speech. Domain has no filesystem, clock, UI or network dependency.
