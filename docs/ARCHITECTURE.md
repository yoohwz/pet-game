# Architecture

`Presentation → Application → Domain`; Infrastructure implements persistence for Application. Domain owns validation, formula-based awake/sleep/survival simulation, absolute-age GrowthModel transitions, canonical `DomainEvent` construction and deterministic biological event ordering, relationship rules, memory projection/query, and pure English-only language normalization/classification from supplied rules and memory. Application owns config loading, care/language candidate transactions, rescue, memorial and new-egg commands, clock synchronization and persistence. Presentation owns the Phase 8 portrait shell, deterministic procedural companion projection, readable needs, lifecycle-stable controls, fixed non-persistent reactions and hidden-by-default developer diagnostics; it never applies biological/language rules, persists directly or generates pet speech. Domain has no filesystem, clock, UI or network dependency.
